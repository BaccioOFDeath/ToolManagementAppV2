One-line: the brand's content surface — hairline border before shadow, near-square corners, shadow only on hover.

```jsx
<Card media="/img/part.jpg" meta="BMW · Genuine" title="Water Pump — N20" interactive footer={<Button size="sm">Add to Cart</Button>}>
  Fits F20/F30 2011–2016. In stock, ships overnight.
</Card>
```

Variants: default (white + hairline), subtle (grey fill, no border), inverse (black band content), accent (yellow — one per view, for a promo or CTA only).
