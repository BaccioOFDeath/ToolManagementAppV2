One-line: SD European's action control — use `primary` (yellow) for the single main action on a view and `secondary` (black) for everything else.

```jsx
<Button variant="primary" size="lg" iconRight={<Icon name="arrow-right" size={20} />}>Book a Service</Button>
```

Variants: primary (yellow/black), secondary (black/white), outline, ghost, inverse (white — black backgrounds only). Sizes sm 34px / md 44px / lg 54px. Labels are Title Case verb phrases. Hover darkens, press shrinks 1.5% — never fade on hover.
