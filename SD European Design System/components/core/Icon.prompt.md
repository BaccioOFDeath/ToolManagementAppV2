One-line: renders a Lucide glyph at the brand's stroke weight, inheriting `currentColor` — use for every icon rather than inlining SVG.

```jsx
<Icon name="phone" size={20} label="Call us" />
```

Requires `<script src="https://unpkg.com/lucide@latest"></script>` on the page. Icons are never filled, never yellow on light backgrounds, and never sit inside a coloured chip.
